# Windows 설치·폴더 연결

1. [공식 다운로드 페이지](https://lunalab-ai.com/download/?lang=KO)에서 `LunaFolderConnector-0.8.2-win-x64.msi`를 받습니다. 릴리스의 SHA256SUMS.txt와 파일 해시를 비교할 수 있습니다: `Get-FileHash .\LunaFolderConnector-0.8.2-win-x64.msi -Algorithm SHA256`. 버전이 포함된 파일명과 설치파일을 유지하세요.
2. MSI를 실행합니다. 현재 Windows 사용자에게 설치하며 별도 .NET 설치가 필요 없습니다. 현재 미서명 검증판이므로 학교·Windows 정책이 차단하면 관리자에게 문의하세요.
3. 시작 메뉴의 LUNA Folder Connector를 엽니다. 계정 → LUNA 로그인을 누르고 일반 브라우저의 계정·확인 코드를 확인하여 승인합니다. 계정 연결에서 프로젝트는 고르지 않습니다.
4. 내 폴더 → 새 폴더 추가에서 OneDrive 자동 찾기 또는 폴더 선택을 누릅니다. 공식 OneDrive 앱이 PC에 동기화한 실제 폴더가 필요합니다. Entra 앱 등록이나 Microsoft 비밀 값은 필요 없습니다.
5. 등록할 프로젝트를 선택합니다. 하위 폴더·온라인 전용 파일 다운로드·프로젝트 공유 범위를 검토하고 자동 등록에 동의합니다. 웹의 프로젝트 화면에서 프로그램을 열면 프로젝트 선택 후보를 전달할 수 있습니다. 후보는 자동 업로드 동의가 아닙니다.
6. 내 폴더에서 폴더 → 연구과제 → 프로젝트, 서버 접수·원본 보존·본문 추출을 확인합니다. 여러 폴더를 추가하고 개별 중지·해제할 수 있습니다. 웹의 과제·프로젝트 → 외부자료 연결과 프로필 → 내 PC·동기화 관리에서도 같은 연결을 봅니다.

## 일시중지·삭제·업데이트

같은 Windows 사용자로 기존 앱 위에 설치하며 먼저 제거하지 않습니다. 0.8.2부터 같은 버전 재설치도 지원하고, Windows가 이미 설치한 패키지의 원본을 사용자 전용 캐시에 보관해 이름이 달라진 다운로드 사본에서도 다시 찾도록 합니다. 설치 실패 화면에는 자동으로 생성된 MSI 로그 위치가 표시됩니다. 문의 시 로그를 보관하고 Windows 보안 정책이나 연결 설정을 바꾸지 마세요.

웹에서 접수를 허용해도 PC의 전체·개별 일시중지는 유지됩니다. PC가 꺼졌거나 로그아웃했으면 다음 연결을 기다립니다. 폴더 연결 해제는 해당 폴더의 미래 전송만 중지합니다. PC 원본, LUNA 자료·버전, 관리자 보존 사본, 추출 정보를 삭제하지 않습니다. 복원은 같은 ID를 유지하며 PC에서 범위를 재확인할 때까지 접수를 중지합니다.

Windows 로그인 후 자동 실행은 설정에서 선택합니다. 창을 닫으면 트레이에 남고 완전 종료는 트레이 메뉴에서 합니다. 업데이트 전에 트레이에서 완전히 종료하고 새 MSI를 실행하세요. 기존 설정·자료 이력·일시중지 선택을 유지합니다. 게시자 인증서가 준비되기 전 자동 설치 실행은 지원하지 않습니다.

PC → LUNA 단방향이며 로컬 삭제를 LUNA 삭제로 전파하지 않습니다. 자동 유료 AI는 실행하지 않습니다. 온라인 전용 파일 다운로드는 기본 꺼짐이고 네트워크 비용은 별도입니다. OneDrive 클라우드 최신성은 PC 접수와 별도입니다.

[문제 해결·한영 도움말](https://lunalab-ai.com/workspace/help/folder-sync/) · iOS는 추후 개발 예정입니다.

## 연구실 Drive 보존

관리자가 이미 연결한 비공개 보존소를 사용합니다. 과제 → 프로젝트 → 연결 폴더 아래에 현재 자료 바로가기, 원본 버전, 버전별 JSON 보존 목록을 정리합니다. 서버 접수·원본 보존·정리 완료는 별도 상태입니다. 코드·배열·데이터·모델 원본을 보존하며 실행하지 않습니다. 파일당 100 MB, 하루 1 GB와 기존 제외 규칙을 유지합니다. 큰 파일은 서버가 재개 가능한 조각 업로드로 보존합니다. 기존 파일 정리는 웹 폴더 상세의 관리자 검토에서 시작하며 Drive 원본 ID와 버전은 유지합니다. Google Drive 연결·할당량 문제가 있으면 대기/확인 필요 상태를 표시하며 자동 유료 AI는 실행하지 않습니다.

## 0.7.0 동기화와 안내

파일 이벤트와 약 2분 목록 검사를 함께 사용합니다. 시작·변경 감지·약 6시간마다 내용 해시를 확인하므로 같은 이름의 수정본도 새 버전으로 남습니다. 대량 파일은 암호화 목록·처리 위치를 저장해 재시작·다음 일일 한도 이후 이어갑니다. PC 전송 사본은 Drive 보존 확인까지 암호화해 유지하고, 공간이 차면 대기합니다. 폴더 부재는 두 번의 완료 검사와 유예 후 확인하며 보존 원본을 삭제하지 않습니다.

외부자료 연결에서 최근 응답, 검사·대기 건수, Drive 보존, 버전과 업데이트 상태를 따로 확인합니다. 오래된 응답은 PC 전원 종료의 증거가 아닙니다. 새 버전마다 플랫폼 알림·LUNA AI 자동 운영 안내와 확인된 학교 계정의 메일을 준비합니다. 초기 구버전은 직접 MSI를 설치해야 합니다. 게시자 인증서가 없는 현재 검증판의 자동 설치는 실행되지 않습니다. 이후 서명된 배포판은 설정에서 자동 설치를 선택하며 실패한 설치는 자동 반복하지 않습니다.

자료의 원래 이름과 사람의 제목을 보존하며 내용 기반 표시 제목을 별도로 준비합니다. 선택한 AI 요약은 관리자 정책·현재 자료 권한·기존 AI 허용과 예산을 따르고 근거와 확인 범위를 표시합니다.


## 0.8.0 업데이트 버튼과 7일 유예

앱 기본 화면·설정·트레이의 업데이트 버튼을 누르세요. 미서명판은 공식 다운로드 화면에서 파일을 받고 같은 Windows 사용자로 기존 앱 위에 설치합니다. 먼저 제거하지 마세요. 폴더·연결·대기 자료·일시중지를 보존합니다. 최소 지원 버전이 지정되면 7일 후 구버전의 신규 동기화가 제한됩니다. 이미 시작한 전송과 기존 자료·Drive 보존·상태 확인은 유지합니다. 플랫폼의 업데이트 안내에서 PC별 기한과 새 버전 응답을 확인하세요. 구버전에는 버튼이 없으므로 최초 한 번 수동 설치가 필요합니다. Windows·학교 보안 정책은 우회하지 않습니다.

이전 검증판에서 오류 2868이 나오면 0.8.2 이상을 다시 받고 트레이 앱을 종료한 후 기존 앱 위에 설치하세요. 설치 메시지 표시 오류를 수정하며, 그 앞의 다른 설치 실패는 추가 진단이 필요할 수 있습니다. 재현할 때 상세 로그를 남깁니다: `msiexec.exe /i "LunaFolderConnector-0.8.2-win-x64.msi" /L*V "%TEMP%\LunaFolderConnector-setup.log"`. 오류 화면과 관련 오류 줄만 비공개로 문의하세요. 로그에는 로컬 경로가 포함될 수 있습니다. 앱 제거·폴더 설정 삭제·Windows 보안 해제·관리자 강제 설치를 하지 마세요.
